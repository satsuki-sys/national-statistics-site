Japan in Figures — an independent national statistics site for Japan. Population, economy, society and health, with real figures from the Statistics Bureau of Japan, the IMF, the World Bank and Japan's ministries, and the source and year on every number. It runs offline in a browser, on desktop and phone, from its own static files: hash-routed pages, canvas charts, sortable and filterable tables, and a full data-and-sources page.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or open `app/index.html` directly in a browser.
